# Scroll 3D Sequence (`scroll-3d-sequence`)

Skill para construir sitios web inmersivos estilo **Apple / Rolex / Sean Kochel** con reconstrucción 3D fotorrealista controlada por scroll usando:

1. **Keyframes Multi-Ángulo** (macro interior, órbita 35°–45°, hero final).
2. **Video AI Encadenado** (`gemini-omni-1.2-flash` / Veo / Higgsfield) con movimiento de cámara real (`10s–15s`, `1080p`).
3. **Extracción FFmpeg a Secuencia WebP** (`240–360+` fotogramas ligeros).
4. **Renderizador HTML5 `<canvas>` a 60fps** con precarga progresiva por prioridad y `requestAnimationFrame` + `lerp`, sin WebGL pesado.

## Instalación en Antigravity / Agentes IA

Copia `SKILL.md` dentro de tu carpeta global de skills:

- **Windows:** `C:\Users\<tu-usuario>\.gemini\config\skills\scroll-3d-sequence\SKILL.md`
- **macOS / Linux:** `~/.gemini/config/skills/scroll-3d-sequence/SKILL.md`
